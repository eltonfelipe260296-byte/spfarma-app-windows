# SPFARMA — Aplicativos para Windows e Android

## Windows 0.32.0

[Baixar instalador Windows x64](https://github.com/eltonfelipe260296-byte/spfarma-app-windows/releases/latest/download/SPFARMA-Flutuante-Instalador.exe)

Na importação de clientes, busque ruas por digitação de rua, bairro, cidade ou CEP para associar endereços ausentes. As janelas de conferência estão mais largas e compactas, com ajustes lado a lado em telas 2560×1080. Em Vendas, os endereços salvos ficam visíveis para seleção direta.

Formato XLSX/XLS, ajuste de telefones duplicados, IDs sequenciais e histórico preservados. Instale por cima da versão atual, sem desinstalar. Conclua as vendas antes de atualizar.
