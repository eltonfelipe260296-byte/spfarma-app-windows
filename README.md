# SPFARMA — Aplicativos para Windows e Android

## Windows 0.29.0

[Baixar instalador Windows x64](https://github.com/eltonfelipe260296-byte/spfarma-app-windows/releases/latest/download/SPFARMA-Flutuante-Instalador.exe)

Cadastro de clientes com ID automático, telefone único pelos oito últimos dígitos e histórico de pedidos. A importação Excel mantém as sete colunas anteriores e permite atualizar ou ignorar clientes existentes, cadastrar ruas ausentes ou associá-las à base de taxas.

Instale por cima da versão atual, sem desinstalar. Conclua as vendas antes de atualizar. O servidor foi publicado junto com as regras de identidade e importação.
