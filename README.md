# SPFARMA — Aplicativos para Windows e Android

## Windows 0.31.0

[Baixar instalador Windows x64](https://github.com/eltonfelipe260296-byte/spfarma-app-windows/releases/latest/download/SPFARMA-Flutuante-Instalador.exe)

A importação abre uma janela de ajuste manual quando o telefone se repete na própria planilha. Escolha ou corrija nome e telefone, edite os endereços e marque quais deseja cadastrar. Dois ou mais endereços diferentes podem ficar no mesmo cliente; endereços idênticos são salvos uma vez. Cancelar não grava dados.

IDs sequenciais, histórico, formato Excel, escolha de atualizar/ignorar clientes existentes e cadastro/associação de ruas preservados. Instale por cima da versão atual, sem desinstalar. Conclua as vendas antes de atualizar.
